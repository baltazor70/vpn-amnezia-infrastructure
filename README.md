# 🛡️ VPN Amnezia Infrastructure

Персональный VPN-сервер на базе AmneziaWG для семьи и друзей. Лёгкий, безопасный, с полным мониторингом и автоматизацией. Спроектирован специально для VPS с ограниченными ресурсами.

**Стек:** Ubuntu Server 24.04 LTS, AmneziaWG (Docker), Nginx, Flask, Bash
**Управление:** Telegram-бот, система cron-скриптов, веб-панель (Flask)

---

## 🎯 Для кого этот проект

Это решение **специально спроектировано для VPS с ограниченными ресурсами** (1 ядро, 1 ГБ ОЗУ, 15 ГБ SSD). Вместо установки тяжеловесных систем мониторинга (Prometheus, Grafana, Zabbix) здесь используются **лёгкие Bash-скрипты и Telegram-бот**, которые не нагружают сервер.

**Что это даёт:**
- **Экономия ресурсов.** Никаких лишних демонов и веб-интерфейсов, всё работает через cron и Telegram.
- **Простота поддержки.** Все скрипты написаны на Bash и Python, их легко читать и править.
- **Прозрачность.** Вы всегда знаете, что происходит на сервере, и можете быстро найти проблему.

**Этот проект для вас, если вы:**
- Хотите развернуть свой VPN-сервер для семьи и друзей, но не готовы платить за дорогие тарифы.
- Ищете практический кейс для изучения Linux, сетевой безопасности и автоматизации.
- Устали от перегруженных инструментов и хотите минималистичное, но надёжное решение.
- Хотите понимать, как работает VPN-инфраструктура «под капотом», а не просто нажимать кнопки.

**Этот проект НЕ для вас, если:**
- Вам нужен коммерческий VPN-сервис с биллингом и личным кабинетом.
- Вы ищете решение «из коробки» для тысяч пользователей.
- Вы не готовы потратить пару часов на чтение документации и базовую настройку.

## 🚀 Быстрый старт

> **⚠️ Важно:** Установочный скрипт `install.sh` поддерживает только **Ubuntu 24.04 LTS**.

Чтобы развернуть такой же сервер, выполните одну команду:

```bash
curl -s https://raw.githubusercontent.com/baltazor70/vpn-amnezia-infrastructure/main/install.sh | bash
```

Скрипт задаст несколько вопросов (токены, пароли) и всё настроит автоматически.

Для проверки уже установленной системы можно запустить:

```bash
bash install.sh --check
```

Он проверит все компоненты и покажет отчёт, ничего не изменяя.

✨ Ключевые возможности

🔒 Безопасность

· Доступ по SSH только с ключом, парольная аутентификация отключена.
· Fail2ban защищает SSH и веб-интерфейс (бан на 1 час после 3 неудачных попыток).
· UFW с минимальным набором открытых портов: 22 (SSH), 443/udp (VPN), 45678/tcp (веб-статус).
· Все пароли и токены вынесены в защищённый .env-файл (права 600).
· Автоматические обновления безопасности (unattended-upgrades).

🧠 Мониторинг и уведомления

· Telegram-бот с полным набором команд для управления и диагностики.
· Веб-панель (Flask + Nginx) — защищённая паролем страница для проверки статуса сервера и VPN без доступа к Telegram.
· Уведомления о подключениях/отключениях клиентов с точным определением имён.
· Защита от «зомби»-пиров и дублирующихся уведомлений.
· Отслеживание ресурсов сервера (CPU, RAM, диск) с алертами при превышении порогов.

⚙️ Автоматизация

· Watchdog для автоматического перезапуска контейнера Amnezia.
· Ежедневные бэкапы конфигураций WireGuard и скриптов.
· Автоматическое удаление «потерянных» профилей (сирот) каждый час.
· Аудит пиров одной командой с полной информацией по каждому клиенту.
· Сбор метрик (CPU, RAM, диск, сеть) каждые 15 минут для построения графиков.

👨‍👩‍👧‍👦 Удобство для пользователей

· Веб-страница проверки статуса VPN (Flask + Nginx + самоподписанный SSL) с парольной защитой.
· Понятные имена клиентов в уведомлениях и статистике.
· Вся статистика и управление — через Telegram.

📋 Команды Telegram-бота

Команда Назначение

/logs Последние логи бота
/help Справка по всем командам
/start Приветственное сообщение

🌐 Веб-панель (Flask)

Доступна по HTTPS на порту 45678. Требует пароль (задаётся в .env). Показывает:

· Статус VPN-сервиса (контейнера)
· Статус сервера
· Пинг до Cloudflare и Яндекса
· Ресурсы сервера (CPU, RAM, диск) — в реальном времени
· Графики ресурсов и сетевой активности (за последние 24 часа, шаг 15 минут)

Безопасность: самоподписанный SSL-сертификат, fail2ban защищает от перебора пароля.

📂 Структура репозитория и описание скриптов

1. vpn-bot-listener.sh — основной Telegram-бот

Главный интерфейс управления и мониторинга. Работает как фоновый процесс (vpn-bot.service), взаимодействует с администратором через Telegram API.

Принцип работы:

· Запускает бесконечный цикл, получает сообщения от Telegram через getUpdates.
· Обрабатывает команды и выполняет диагностические команды на сервере через docker exec и wg show.
· Отправляет результаты обратно в Telegram через sendMessage.

Безопасность: административные команды доступны только владельцу (проверка по CHAT_ID). Токен хранится в /root/.vpn-env.

---

2. vpn-alert.sh — уведомления о подключениях и отключениях

Запускается каждые 2 минуты через cron. Отслеживает изменения в списке активных пиров.

Принцип работы:

· Получает текущий список внутренних IP из wg show.
· Сравнивает с предыдущим снимком (/tmp/vpn-peers-state).
· Если появился новый IP — отправляет уведомление о подключении. Если IP исчез — уведомление об отключении.
· Имя пользователя определяется по IP через clientsTable (только по полю allowedIps).

Особенности: не отслеживает ключи — только IP. Не спамит при кратковременных обрывах.

---

3. audit-peers.sh — полный аудит пиров

Инструмент для ручной проверки состояния всех пиров.

Принцип работы:

· Собирает данные из wg show и clientsTable.
· Выводит таблицу: IP, публичный ключ, имя пользователя, последний handshake, трафик.
· Ищет имена только по allowedIps, игнорируя allowed_ips.

---

4. cleanup-orphans.sh — удаление «сирот»

Запускается каждый час через cron. Автоматически удаляет пиров, которых нет в clientsTable, но которые остались в awg0.conf.

Принцип работы:

· Сравнивает список IP из awg0.conf со списком имён из clientsTable.
· Если IP есть в конфиге, но для него нет clientName — удаляет его ключ из WireGuard.
· Отправляет уведомление в Telegram об удалении.

---

5. resource-monitor.sh — мониторинг ресурсов

Запускается каждые 5 минут. Следит за CPU, RAM и диском.

Принцип работы:

· Собирает метрики через top, free, df.
· Если превышены пороги (CPU > 90%, RAM > 90%, Disk > 80%) — отправляет алерт в Telegram.

---

6. vpn-monitor.sh — ежедневный отчёт

Запускается дважды в сутки (9:00 и 21:00). Отправляет полный статус сервера в Telegram.

Принцип работы: аналогичен команде /status в боте. Собирает данные о клиентах, трафике, ресурсах контейнера и хоста, пинге.

---

7. metrics-logger.sh — сбор метрик для графиков

Запускается каждые 15 минут. Сохраняет CPU, RAM, диск и сетевой трафик в лог-файлы. Данные используются для отрисовки графиков на веб-панели. Хранятся только последние 24 часа (96 записей).

---

8. Прочие скрипты

· backup-docker.sh — бэкап конфигов WireGuard и скриптов.
· cleanup-server.sh — очистка Docker, логов, apt.
· auto-reboot.sh — плановая перезагрузка с обновлениями.
· post-reboot-check.sh — проверка состояния после перезагрузки.
· vpn-container-watchdog.sh — авто-восстановление контейнера.

---

📊 Логика идентификации пользователей

Все скрипты используют единый метод определения имени пользователя по IP:

1. Поиск в clientsTable (JSON-файл внутри контейнера Amnezia).
2. Только по полю allowedIps, игнорируя allowed_ips (чтобы избежать дубликатов).
3. Имя жёстко привязано к внутреннему IP и не меняется.
